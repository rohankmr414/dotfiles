# Original desktop setup

These are the original i3/bspwm-era dotfiles, preserved without modifying their content
or executable modes. The old README remains alongside them.

Source: https://github.com/rohankmr414/dotfiles

Original master commit: `673a3fd02c7b5eaf0c775747f0375adf43bb8c43`.

The restructure keeps that commit in Git history. Its files, including the i3lock
PNG, are moved here using their original Git blob IDs. This directory is excluded
from all installation scripts.
